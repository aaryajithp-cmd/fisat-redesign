# FISAT redesign — outcome work items

- [x] **Global design, navigation, accessibility and responsive system.** The site feels like a premium modern engineering university in Kerala and distinctly FISAT—not a SaaS site, startup landing page, developer portfolio, generic Bootstrap template, AI-generated template or cyberpunk site. Use a disciplined palette of black #000000, white #FFFFFF and the signature blue #2C3480, with only compatible neutral gray surfaces and text; remove gold and unrelated accent hues. Use an editorial display font (Instrument Serif / Playfair Display / similar) and Inter / Geist / Manrope body; expressive headings, readable copy, clear hierarchy and generous whitespace. Every internal page has global navigation, a page-specific hero, breadcrumb, content, contextual navigation where appropriate, CTA and footer; hero layouts differ by page. Shared navigation has utility links Student Portal, Faculty, Alumni and Contact; main links About, Academics, Admissions, Campus Life, Facilities, Research, Placements, Search and Apply Now; Academics includes Programmes, Departments, Faculty, Academic Environment, Research; Campus Life includes Hostel, Cafeteria, Sports, Fitness, Clubs, Arts & Culture, Events; Facilities includes Library, Laboratories, Computing, IDEA Lab, Robotics, Auditorium, Transportation, Bank & ATM. Mega menu supports hover/focus, subtle Motion transitions, keyboard access, mobile equivalent and active page state; mobile uses a full-screen animated drawer. Use semantic HTML, ARIA, keyboard navigation, visible focus, accessible dropdowns/accordions, alt text, color contrast and reduced-motion support. Keep the initial static HTML visible before hydration—including the global page shell, first facility tab and selected campus-explorer detail—and do not hide required content if JavaScript is disabled; run Motion entry/exit effects only after hydration or user selection. Design independently for 360/390/430/768/1024/1280/1440px with large touch targets, no horizontal overflow, readable type, simplified mobile bento, swipeable galleries, accessible accordions and useful sticky CTA. Use Next.js, React, TypeScript, Tailwind CSS, Motion and Lucide React; optimize images, fonts, JavaScript and animation; use AVIF/WebP, lazy loading, responsive images and code splitting; remain fast on Indian mobile networks; avoid heavy WebGL, unnecessary Three.js, autoplay video and huge image assets. Use reusable components for Navbar, MegaMenu, PageHero, Breadcrumb, SectionHeading, StatCard, ImageCard, FeatureCard, DepartmentCard, FacultyCard, FacilityCard, NewsCard, EventCard, Timeline, Gallery, FilterBar, SearchBar, Accordion, Tabs and Footer; keep structured content in data modules. Adapt the 21st.dev Scroll Reveal Image pattern for the cinematic hero, the Bento Grid pattern for asymmetric campus discovery, and the Transition Panel pattern for responsive content switching; use FISAT imagery and custom semantic/ARIA components, not the source pages’ stock images or unmodified default styling.
